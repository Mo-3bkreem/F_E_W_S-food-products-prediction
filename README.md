# FEWS - Food Early Warning System

## Overview
An AI-powered system for predicting food price fluctuations and detecting market risks.

## Features
- Price Forecasting
- Risk Scoring System
- Interactive Dashboard (Streamlit)
- Crisis Simulation

## Tech Stack
- Python
- Streamlit
- Pandas
- Plotly

## How to Run
pip install -r requirements.txt
streamlit run app.py
